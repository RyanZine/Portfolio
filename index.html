Projetos

~/projects/classifier

Classifier

Trilhas de estudo com Machine Learning + LLM

Uma rede neural própria em TensorFlow.js classifica o perfil do aluno e recomenda o plano; uma LLM com escopo fechado (Gemini) monta a trilha de estudos usando só o catálogo da plataforma, com saída em JSON validada e trilha padrão como plano B. Os dados entram por uma API Fastify com JSON Schema, o feedback dos alunos alimenta o retreino do modelo e um simulador roda a classificação direto no navegador.

  • TensorFlow.js
  • Node.js
  • Fastify
  • Gemini
  • node:test
